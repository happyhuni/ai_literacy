# 강의/세미나 요약

- 일시: 2026-04-24
- 주제: AI 교육 - 생성형 AI 이해 및 활용

## 개요

- 핵심 메시지: **AI를 잘 쓰는 것은 기술/프롬프트 스킬이 아니라 "내 분야에 대한 전문성"에서 나온다**

## AI 사용 현황

- OpenAI 발표 통계: 전 세계적으로 **AI 미사용 84%, 무료 사용 6%, 유료 0.2%, 코딩 활용 0.04%**

## AI를 잘 쓴다?

- 좋은 답변의 3가지 기준: 정확성 / 속도 / 내가 원하는 답
- LLM 특성상 **정확한 답을 항상 주지는 않음(항상 거짓말을 하는 친구)**
- "뭉뚱그려 물으면 뭉뚱그려 답하고, 구체적으로 물으면 구체적으로 답한다" — AI는 입력에 대칭적으로 반응
- 프롬프트 작성 기교(좋은 예시/나쁜 예시)는 강사 본인은 중요하게 생각하지 않음

> "AI를 잘 쓰는 방법: 그 산업, 그 분야에 대해서 잘 알고 있는 사람이 잘 쓴다"

- 이미지 생성 예시: 구도·조명·색감을 구체적으로 말하는 건 "AI를 잘 쓰는 것"이 아니라 **이미지에 대한 이해도가 높은 것**
- **AI 접근성·학습 난이도가 너무 낮기 때문에, 결국 경쟁력은 전문성·경험·깊이에서 나온다**

### 인공지능의 작동 원리 - 학습과 분류

- 인공지능의 본질은 **분류와 예측**
- 학습 데이터에 없는 요소는 분류 불가 → 데이터가 많고 다양할수록 정확도 상승
- 데이터 라벨링(초록 박스/빨간 박스 의미 지정)이 필수, 과거 알바로 박스 하나당 200원 수준으로 수작업
- 의료 분야 활용 예시: 요즘 흉부 엑스레이는 의사보다 AI가 먼저 병명을 읽어내기도 함

### 트랜스포머의 원리

- GPT: Generative Pre-trained Transformer
  - 트랜스포머 알고리즘으로 사전 학습하여 생성하는 모델
  - Pre-training (사전학습): 미리 학습해 둔다는 의미로, 실시간 학습이 아니므로 최신 정보를 모르는 구조적 한계 존재
  - Transformer: 2017년 구글 논문에서 제안된 알고리즘. 다음 단어를 확률로 예측해 생성
- 2017년 구글 논문 "Attention Is All You Need"에서 제안된 알고리즘
- **"머리부터 발끝까지" 다음 단어 맞추기 예시:**
  - 사람마다 "핫이슈", "사랑스러워", "오로나민C", "이근데이" 등 다르게 연상
  - 이유: **사람마다 맥락과 경험이 다르기 때문**
  - 런닝맨 이야기 중이었다면 김종국("사랑스러워") 확률 상승, 나혼자산다 맥락이면 오로나민C 확률 상승
- **트랜스포머 동작 방식:**
  - 정확한 답을 찾는 것이 아니라 **다음에 올 단어를 확률로 예측해 하나씩 생성**
  - 예: "Data Visualization import user2 Generator" → 다음 단어 "and"(36%), ","(22%), "or"(14%) 중 선택
  - 모든 LLM 답변이 이 과정을 거침
  - https://poloclub.github.io/transformer-explainer/

### 할루시네이션(환각) 현상

- **할루시네이션 정의:** 사실과 무관하거나 맥락이 맞지 않는 잘못된 정보를 사실인 것처럼 생성하는 현상
- 트랜스포머를 쓰는 이상 **근본적으로 제거 불가**, 줄이려 노력할 뿐
- 대표 사례: **"세종대왕의 맥북프로 던짐 사건을 알려줘"** → 그럴듯하게 거짓 답변
  - 한국인은 바로 알지만 외국인은 속을 수 있음
- 비판적 사고가 필수 → 그래서 **자기 분야 전문가만이 AI를 제대로 활용 가능**
- 강사의 박사 시절 경험: ChatGPT로 선행연구를 찾았더니 **존재하지 않는 논문을 마치 있는 것처럼 만들어냄**
- 최근에는 출처 표시 기능이 강화됨 (Perplexity, Deep Research 등)

### RAG (Retrieval-Augmented Generation) 개념

- 기존 방식: User → LLM → 답변
- RAG 방식: User 질문 → **데이터베이스/웹에서 관련 내용 검색** → 그 정보를 LLM에 함께 전달 → 답변
- **장점 3가지:**
  1. 최신 정보 반영 가능
  2. 할루시네이션 99% 이상 제거 (근거 정보 기반 답변)
  3. **우리 회사/조직만 가진 데이터로 대화 가능** (공개 데이터로만 학습된 GPT는 내부 자료를 모름)
- GPT의 구조적 한계 때문에 RAG 개념이 생겨남 → 3일차에 본격적으로 다룰 예정

### 회의록 작성

- 네이버가 운영하는 무료 음성 전사 서비스. 앱/웹에서 사용 가능.
- **사용 흐름**: 새 노트 → 녹음 또는 파일 첨부 → 전사 자동 생성 → 키워드 추출 → AI 요약.
- 목소리로 **화자 구분(점유율 표시)** 이 가능하며, 참석자 이름 수동 지정도 가능.
- 다운로드 포맷: 텍스트(메모장), 엑셀(시간·내용 컬럼) -> 다운로드 후 주로 사용하는 AI 사용
- 무료의 경우 전사 및 요약의 사용횟수-시간 제한
- 휴대폰 전사 기능
  - 상대적으로 느리고 품질이 떨어짐
  - AI 요약이 충분히 보완 가능 -> 클로버 대체 가능

### AI 답변 품질을 높이려면?

- 프롬프트 엔지니어링
  - 요즘 회자되는 용어들: **프롬프트 엔지니어링 / 컨텍스트 엔지니어링 / 하네스 엔지니어링**.
  - 본질은 모두 같음:
    > "얘가 잘 알아먹을 수 있도록 그냥 구체적으로 말을 쌓아놓는 것. 구체적으로 말하는 거예요. 그 정도 수준이지."
- 모델에 따른 답변 품질 차이 비교
  - 동일 질문("2026년 인공지능 트렌드 보고서 만들어줘")을 무료/유료 모델에 각각 입력.
  - **무료 모델**: 키워드 나열 수준, 보고서 느낌 없음.
  - **유료(Thinking/Pro) 모델**: 참고 자료 출처(가트너, 스탠포드 등) 제시, 보고서 구성 양호.
  - 구체적 지시(목적=임원 보고용, 목차=요약-서론-본론-결론-기대효과, 역할=20년 차 연구원 부여)를 추가하자 양쪽 모두 개선됨.
- **핵심 결론** [21:00]:
  - "답변의 퀄리티는 요즘에는 질문의 차이보다 모델의 차이가 더 큼.
  - 특히 리서치·보고서·회의록 작성은 질문 퀄리티 차이가 크지 않음
- 질문을 잘하는데 자신이 없다면?
  - "AI를 잘 활용하는 법 공부하는 것보다 리더십 책이나 글쓰기 책을 공부하는 게 훨씬 도움
  - 신입 비유: 3~5년 차는 대충 말해도 알아듣지만, 신입은 구체적으로 시켜야 제대로 함. AI도 동일.

### ChatGPT 기타 기능

- 심층 리서치(Deep Research)
  - 플러스 버튼 → 심층 리서치 선택.
  - 연도 범위·출처 등을 지정해 장시간(30~40분) 리서치 수행.
  - 최근에는 전반적으로 처리 시간이 늘어남.
- **음성 대화 / 라이브 비디오**
  - 앱에서 음성 버튼 + 플러스 → 라이브 비디오로 화면을 보여주며 대화.
  - 여행 중, 운전 중 활용도 높음.
- **일정 자동화 (유료)**
  - 예: "매일 9시에 AI 뉴스 요약 알림" 같은 반복 작업을 스스로 수행하고 알림 전송.
- **데이터 제어 설정**
  - '모두를 위한 모델 개선' 옵션: ON이면 대화 내용을 GPT가 학습. 원하지 않으면 OFF.
- **웹 검색 자동 호출**
  - "오늘의 날씨, 스포츠 팀/선수 성적"처럼 날짜 키워드가 있으면 웹 검색을 자동 수행. 약 1년 전부터 가능.
- **외부 앱 연동(비행기표 검색 등)**
  - 예: 도쿄 항공권 검색. 현재 성능은 기대 이하.
  - 작년 "유럽행 10만 원 예매" 바이럴 뉴스 -> 실제 따라 해보니 거짓

### Gemini의 Canvas 기능

- Gemini에서도 동일한 트렌드 보고서 요청 → Canvas 도구 선택.
- **Canvas 장점 1 — 즉시 편집**: 답변이 편집 가능한 문서로 열림. 길이·폰트 수정 가능.
- **Canvas 장점 2 — 어조 변환**: 매우 편하게 / 편안하게 / 정중하게 / 매우 정중하게 원터치 변환.
  - "매우 편하게" → 카드 뉴스·블로그 톤으로 바뀜.
  - "매우 정중하게" → "관측됐다", "사료된다" 같은 격식체로 바뀜.
- **Canvas 장점 3 (가장 추천) — Google Docs로 내보내기**:
  - 바로 Docs로 연결 → 포맷·색상 편집, 문서 탭별 구분, 타인과 동시 편집.
  - 유료 Gemini 사용자는 Docs 내부에서도 Gemini를 호출해 본문을 확장·수정 가능.

### ChatGPT 심층 리서치(Deep Research)

- 2026년 AI 트렌드, 산업 적용를 예시로 결과물의 구조를 보여줌.
  - 서론, 본론(이론적 배경, 실제 적용 사례, 결론, 기대 효과) 등 컨설팅 보고서 형식으로 잘 작성됨.
  - 레퍼런스(예: Stanford HAI)도 함께 첨부.
- 작업 시간: AI는 약 **37분**, 사람이 직접 했다면 최소 **3일**, 길게는 1~2주 소요될 작업.
- 대신 **검토 시간**은 사람이 충분히 들여야 함. 첨부된 레퍼런스가 실제로 존재하는지, 내용이 맞는지 확인하는 데만 하루가 걸릴 수 있음.
- 결론: 모델이 더 똑똑해지는 것보다 **실제 업무를 얼마나 바꾸느냐**가 중요하다는 관점에 동의.

### 레드팀 vs 블루팀 프롬프팅 활용법

- AI에게 "레드팀이 되어 내 보고서를 비판해줘"라고 지시.
- 컨텍스트 설정 팁:
  - 교수님/팀장님/부장님 등 **실제 검토자의 성격과 선호**를 입력 (예: "교수님은 논문 위주의 레퍼런스, 이론적 내용을 선호한다").
  - 그러면 AI가 그 관점에서 비판해줌. 실제로 "보고서 정체성 문제(컨설팅인가 학술인가), 이론적 프레임워크 부재, 단순 트렌드 나열" 등 구체적인 피드백 제공.
- **자존감 보호 팁**
  - 비판만 받으면 자존감이 떨어지므로, "장점도 알려줘"를 함께 요청. (블루팀)
  - 단점을 보완하는 것도 중요하지만 장점을 강화하는 것도 중요
- 레드팀과 블루팀 설정을 번갈아 쓰며 보고서를 디벨롭하는 사이클을 권장.

### Gemini Canvas — 인포그래픽 생성

- Gemini의 Canvas → "만들기" → 인포그래픽 선택
- 보고서 내용을 자동으로 시각화 (5대 핵심 기술 패러다임, 산업별 파급 효과, 결론 및 전략적 제약 등).

  - 단점 1) **자유도가 없음** — 수정이 불가능.
  - 단점 2) **회사/팀 양식·템플릿 반영 안 됨**.
  - 단점 3) 디자인/폰트도 사용자 호불호가 갈리는데 변경 불가.
- 결론: 개인 블로그 등에는 그대로 쓸 만하나, 회사 업무에는 한계.

### Gemini 오디오 오버뷰(Audio Overview)

- Gemini Canvas에서 보고서를 팟캐스트형 대화 오디오로 변환 가능
- 두 명의 진행자가 자연스럽게 대화하며 보고서 내용을 풀어서 설명.

- **NotebookLM**도 동일한 오디오 기능 제공. 모바일 앱으로 다운받아 출퇴근/운전 중 라디오처럼 청취 가능.
- 활용 포인트: **읽을 시간이 없는 보고서를 오디오로 들으면서 빠르게 핵심 파악**.

### GPT 탐색(GPT Store) 활용

- 사이드바의 "GPT 탐색"에서 다른 사람이 만든 전용 GPT를 검색·사용 가능.

- **카드뉴스 GPT**:
  - "카드뉴스 빠르게 만들기" 검색 → 좋아요/댓글 많은 것 선택.
  - 주제(인공지능), 타겟(비전문가), 목적(정보 전달용), 강조 키워드(에이전트 AI) 입력.
  - 결과: 텍스트는 생성되나 이미지는 한 번에 5장이 안 나오는 등 한계 존재.
- **나만의 GPT 만들기**:
  - "만들기" → 구성 단계에서 본인 자료(논문, 연구 내용 등) 업로드 → 그 자료 기반으로만 대화하는 전용 챗봇 구축 가능.
  - 강사의 경우, "박사 논문 GPT"를 만들어 활용 중.

### Gemini Gems(잼스) — 스토리북

- Gemini 사이드바의 **잼스(Gems)** 기능: 스토리북, 브레인스토밍, 코리아 컨설턴트, 코딩 파트너, 카피 크리에이터, 과외 선생 등.
- **스토리북**: 인공지능 보고서를 입력 → 동화책 형태로 변환.
- 평가: 평범하나 **"커스터마이징 없이 이 정도가 나온다"**는 점이 시사적.
- 시사점
  - Gemini는 동화책 전문 툴이 아닌데도 이 정도 결과물 → **동화 전문 AI 툴을 쓰면 훨씬 나은 결과** 가능.
  - 현 시점에서의 관련 AI 서비스 최저선 확인

### NotebookLM

- NotebookLM은 구글이 일반 사용자를 위해 만든 **RAG(Retrieval-Augmented Generation) 툴**. 다른 LLM과 달리 **소스(데이터)를 먼저 넣어야** 대화가 가능함.
- RAG 기반 AI의 기본
- 소스 입력 방법
  - 내 파일 업로드 / 구글 드라이브 / 웹에서 검색(딥리서치·패스트리서치)
  - 무료 플랜: 노트북당 **50개**, 유료(Gemini 구독): **300개**까지
- 실습
  - 웹에서 "인공지능 트렌드" 관련 소스 10개 수집
  - 프롬프트로 소스 평가표 작성: `소스명 / 핵심 요약(100자) / 발행일 / 저자 / 소스 구분(블로그·논문·연구자료·보고서) / 신뢰도(5점) / 참고 가치(10점)`
  - 넣은 소스의 성격부터 먼저 파악하는 습관이 중요.

### NotebookLM 장점

- **할루시네이션이 없음** — 내가 넣은 데이터 기반으로만 답변하므로 거짓말하지 않음.
- **출처 추적 가능** — 답변 옆 숫자를 누르면 어느 문서의 어느 구간을 참고했는지 바로 확인. GPT/Gemini에 PDF를 넣는 것과 결정적으로 다른 점.
- **노트북 단위 공유** — 우리만의 매뉴얼/내부 자료로 노트북을 만들어 팀원에게 공유 가능(온보딩 자료로 유용).
- **주의**: 답변은 화면을 벗어나면 날아감. 필요하면 **"메모에 저장"** 필수.
- 부가 기능
  - **마인드맵**: 키워드 중심 정리, 클릭하면 해당 주제로 추가 질문 생성
  - **슬라이드 자료 생성**: 그럴듯한 템플릿 자동 생성. 단, PPT로 다운받아도 **이미지 형태**라 수정이 번거로움(프롬프트로만 수정 가능)
  - **AI 오디오 개요(팟캐스트형)**: 토론/발표/요약/비평 형식 선택 가능. 운전 중 듣기 등 활용
  - **퀴즈/플래시카드, 보고서, 인포그래픽, 동영상** 등
- 유튜브 요약 관련 변화
  - 최근 유튜브에 Gemini가 내장되어, 영상 옆 "질문하기" 버튼으로 바로 요약 가능. 과거의 유튜브 요약 서비스(릴리스 AI 등)는 구글이 사실상 시장에서 밀어낸 형국.

### AI 서비스와 보안 이슈

- 클라우드 기반 AI는 입력이 **서버로 전송**되는 구조 — 근본적으로 피할 수 없음.
- 해결 방향: **온디바이스 AI(로컬 모델)**.
- 각 기업(OpenAI, Google, Anthropic 등)은 "학습에 사용하지 않는다"고 주장. OpenAI는 학습 여부를 사용자가 on/off 할 수 있음. 다른 곳은 기본적으로 off.
- **비즈니스 계정**을 쓰면 가상 서버(전용 클라우드)를 제공받아 **트래킹(모니터링)이 가능** — 데이터가 정말 거기 머무는지 검증할 수 있음.
- 실무 가이드
  - 대기업 R&D 자료, 개인정보는 **절대 공개 클라우드 AI에 넣지 말 것**
  - 필요 시 **마스킹**(이름·연봉·식별자 암호화) 후 사용
  - 미국 기준 보안 S급 3사: **팔란티어, 아마존, MS 또는 오라클**
  - 중국 AI 서비스 기피 이유 — 가격 대비 성능은 뛰어나지만, 국가가 요구하면 데이터를 제공해야 하는 구조.
- 결국 이 시스템을 의심 -> 지금 돌아가는 전 세계 클라우드 시스템을 의심

### 데이터 고갈과 Anthropic의 중고책 전략

- 온라인의 학습 가능한 데이터는 거의 소진됨. 오히려 AI가 생성한 데이터가 늘어 **자기 학습(self-training)**이 시작되면서 품질이 치우칠 위험.
- **Anthropic(Claude)**은 "질 좋은 데이터는 책에 있다"는 판단으로 **중고책을 대량 구매·스캔해 학습**.
- 결과: Claude가 "가장 사람처럼 글을 쓰는 AI"로 평가받음.
- 저작권 논쟁 [36:04]
  - 기업 주장: "사람이 공부하는 것과 같다 — 원본을 저장하는 게 아니라 확률·패턴을 학습할 뿐"
  - 미국 법원: 현재는 **저작권 침해 아님**으로 판결 진행 중.

### AI 거품론

- OpenAI: 매출 430억 달러 / 손실 135억 달러 — **AI로 돈 버는 회사가 거의 없음**.
- 구조적 한계
  - 개발·인건비 고비용
  - 사용자가 늘어도 단위 비용이 거의 안 줄어듦(질문마다 GPU가 돈다)
  - **헤비 유저 편중**: 200달러 요금제 사용자들이 자동화로 종일 돌려 쓰는 탓에 오히려 적자 심화(클로드가 최근 Claude Code 접근을 100달러 이상 구독자로 제한하려다 2시간 만에 철회한 사례)
- **순환 투자 구조**
  - 엔비디아 → OpenAI에 수십조 투자
  - OpenAI → 그 돈으로 엔비디아 GPU 구매, 아마존 클라우드 임대
  - 아마존 → 그 돈으로 엔비디아 GPU 구매
  - 6개 회사가 서로 투자·장비 구매로 얽혀 매출이 순환.
- **실제 돈 버는 곳**: 하이닉스, 엔비디아, TSMC, 에너지 회사 등 "골드러시의 청바지·곡괭이" 포지션.
- 설국열차 -> "멈춰버리면 다 같이 죽어요. 멈출 수 없어서 다 같이 달려야 돼요."

### AI에 집착하지 말고 문제에 집중하라

- 10년 전 **"빅데이터" 열풍**과 똑같은 함정
  - "우리도 데이터 많으니까 뭔가 해보자"
  - 결과물은 예쁘지만 **아무도 쓰지 않는 쓰레기**로 끝남.
- 데이터 통합이 안 되는 것은 **기술 문제가 아니라 문화 문제**
  - 팀 간 "왜 우리 데이터를 달라 하냐" 식의 장벽.
- AI 도입의 올바른 방향:
  - 먼저 "우리 문제가 뭔가?" → "해결하면 어떤 효과?" → "그럼 어떤 데이터가 필요하지?" → "없으면 만들자/사자"
  - 자동화도 만능 아님 — 사람이 검토해야 할 지점은 남겨두기.
- 우리가 너무 'AI 써야지 AI 써야지' 보다는, 우리가 갖고 있는 문제가 뭐냐 — 이것부터 집중하는 게 AI를 도입할 때 훨씬 더 의미 있음.

### AI로 인한 해고와 천문학적 투자의 역설

- 최근 해고의 약 절반이 AI·자동화가 원인으로 발표됨 -> 이는 전년 대비 40% 증가한 수치.
- 동시에 2025년 한 해에만 기업들이 AI에 약 8천억 달러(약 700조 원)를 투자, 전년 대비 130% 증가.
- "수만 명을 내보내는 바로 그 순간에 AI에 천문학적 돈을 쏟는다"

### 현 시점의, AI가 만든 영상 수준

- **트루먼쇼 AI 재해석 영상**
  - 짐 캐리가 젊은 시절 촬영했던 원작의 20대 외모 재현은 살짝 어색하지만, 감독(크리스토프 역) 재현은 매우 흡사.
  - 가짜 세계에서 빠져나온 주인공이 현실에서 연예인이 되어 첫사랑을 만나고 절망, 감독이 아들처럼 챙겨주는 식의 2차 창작 스토리까지 자연스럽게 전개됨.
- 노홍철 AI 광고 사례 — 연예인 IP 대여 모델
  - 노홍철이 최근 롯데오(추정) 광고에서 **광고료가 아닌 "IP 사용료"를 받았다**고 밝힌 사례를 소개.
  - 본인이 직접 촬영하지 않고 얼굴·이미지권만 빌려주고 영상은 AI로 제작.
  - 시사점:
    - 영화는 아직 AI 제작에 시간이 걸리지만, **광고(10~15초)는 일관성·재현성 부담이 작아 AI로 충분히 대체 가능**.
    - 연예인·인플루언서가 실제로 촬영장에 나오지 않아도 되는 시대가 임박.
- AI 영상 제작 단가 — "비싸 보이지만 실은 싸다"
  - AI 영상 제작 비용이 대략 5분에 5만 원 수준.
  - 처음엔 비싸다고 느꼈으나, 영상 제작 종사자 입장에서는 매우 저렴.
    - 기존 촬영: 감독·카메라·조명·배우·공간 대관·외부 촬영 시 구청 신고 등 비용 누적.
    - AI: 이 모든 과정을 생략.
  - 마블 vs 드래곤볼, 나루토 vs 원피스 같은 크로스오버 팬 영상이 유튜브에 다수 존재 —> "무조건 배척할 게 아니다"

### NotebookLM 을 사용한 키오스크 사용 가이드 만들기

- 새 노트북(NotebookLM) 생성 → 소스 추가 → 이미지 업로드.
- 강사 학교 키오스크를 영상 촬영 후 캡처한 12장의 사진(화질·구도 열악) 업로드.
- 업로드만으로도 NotebookLM이 자동으로 이미지 내용을 요약:
  - "음료·간식 주문 전체 과정을 보여준다. 사이즈·옵션 설정, 바구니, 카드 결제 가능."
- 프롬프트: "키오스크 사용 가이드라인 만들어줘" → 슬라이드형 자료 생성(화장품 버튼 클릭, 길이는 짧게 설정).

### Nano Banana (나노바나나)

- 구글이 만든 이미지 생성 AI로, Gemini에서 바로 사용 가능.
- 접근 방법: Gemini에서 "이미지 만들기" 혹은 도구 메뉴에서 선택.
- **기존 이미지 활용 편집(합성·배경 변경)**에 강점
- 기존 이미지 생성 AI들이 **가장 못했던 것이 일관성·재현성**: 기존 배경·인물 특징을 유지하면서 일부만 수정하는 일이 어려웠음.
- Nano Banana는 **전처리·별도 튜닝 없이도 원본의 모습을 그대로 지킴** → 이것이 차별점.
- 다른 합성 서비스에서는 얼굴이 바뀌어버리는 경우가 많지만, Nano Banana는 그런 현상이 없음.

### Nano Banana 사용 예

- 들고 있는 물건 바꾸기
  - 손흥민 피자 광고 이미지 + 아이스아메리카노 이미지 업로드
    - 시도: "손흥민이 들고 있는 피자를 커피로 바꿔줘"
  - 결과: 캡슐 커피가 뒤집어진 채로 잘못 나오는 등 첫 시도는 어색.
  - 재시도: 잘 바뀜. 첫 결과물이 실패해도 재생성·프롬프트 조정으로 개선 가능.
- 옷 갈아입히기
  - "손흥민 옷을 갈아입혀줘"
  - 결과: 옷은 갈아입혀졌으나 손이 원본보다 커지고(왕손 현상), 모자 때문에 얼굴 비율이 짧아 보이는 현상.
  - **작은 디테일이 무너지는 부분은 여전히 AI 편집의 한계**.
- 인물 교체·포즈 변경
  - "손흥민을 일론 머스크로 바꿔줘" → 자연스럽게 교체됨.
  - 포즈 이미지를 별도로 제공한 뒤 "이 포즈로 바꿔줘" → 포즈 그대로 재현.
- 배경교체
  - "배경을 트럼프 타워로 바꿔줘"처럼 간단한 프롬프트로도 배경이 꽤 그럴듯하게 바뀜.
  - 합성 티가 일부 남지만, 허위 정보·이미지 조작 가능성을 체감하게 하는 핵심 포인트.

### 활용 사례 확장

- 매거진 표지·패션·차량 도면
- 이미지 여러 장을 넣고 "매거진 표지처럼 만들어줘" → 그럴듯한 편집 결과물.
- **패션 업계에서는 실무 활용이 이미 진행 중** — 디테일한 부분만 실제 촬영하고 나머지는 AI로 대체.
- 반면 음식 쪽은 아직 덜 활용되는 편.
- "차량 도면 만들어줘" → 정확한 공학 도면은 아니지만 도면 스타일 이미지 생성 가능.

### 합성 윤리와 제도

- 남성 인물에게 "상의 탈의 해줘"라고 하면 실제로 해줌 → 악용 가능성 시사.
- 한국은 작년부터 **미성년자 SNS 비공개 운영만 허용**.
- 호주는 **미성년자 SNS 사용 자체 금지**.
- 처음엔 개인의 자유 침해 의견 -> 합성 기술의 현재 수준을 감안하면 **"그래도 되는 것 같다"**.

### 이미지 생성을 위한 프롬프트 작성 팁

- 이미지·사진·디자인에 대한 배경지식이 부족하면 어떤 프롬프트를 써야 할지 모르는 경우가 많음.
- 해결책: AI에게 **"프롬프트를 써 달라"**고 요청하기.
  - 원하는 이미지 예시를 첨부하고 "구도·배경·색감·스타일·조화·카메라 렌즈 등 다양한 요소로 상세 분석해서 프롬프트로 작성해달라"고 요청.
  - 얻은 프롬프트를 이미지 생성 AI에 그대로 입력.
- 일부 용어(예: "광각 렌즈")의 의미를 몰라도 원하는 요소(예: 텍스트 "커피", 눈 오는 배경, 계절 겨울)만 수정하면 충분.
- AI의 가장 큰 강점은 **접근성이 높다(허들이 낮다)**는 점.

### 노트북LM으로 키오스크 사용 가이드라인 만들기

- 키오스크 영상 캡처 이미지만 넣고 "사용 가이드라인 만들어줘"로 요청.
- 결과: "매장/포장 → 음료 고르기 → 옵션 → 결제하기" 단계별로 그럴듯한 가이드를 자동 생성.
- 영상에서 저화질로 캡처한 이미지로도 충분히 작동.
- **스타일 파일 지정 팁**: 마블 코믹스 스타일 이미지를 업로드한 뒤 "이 스타일을 반영해서 가이드라인을 만들어줘"라고 요청하면 해당 스타일(아이언맨 일러스트 등)로 재작성해줌.
- 회사 템플릿/디자인 정의서를 업로드하면 사내 디자인 규격에 맞춰 슬라이드 자료를 만들 수 있음.

### Claude로 파워포인트 슬라이드 자동 제작

- PowerPoint 2016 이상 → **추가 기능**에서 "Claude by Anthropic" 검색·설치.
- 기존 강의용 PPT 템플릿을 열어두고 Claude에게 요청:
  - "이 양식에 맞춰 슬라이드 아래 내용을 요약해서 슬라이드 덱을 만들어줘."
  - 선택: 폰트·색상·"한 슬라이드에 최대 3가지 색상" 같은 제약 명시.
- 동작 방식: Claude가 템플릿의 폰트·배경·주요 색상을 먼저 분석 → 슬라이드 구조 설계 → 핵심/약/중 압축(분량 조절 가능) → 페이지별 생성.
- **Claude의 4가지 장점**:
  - 템플릿을 알아서 분석·반영 (폰트/색상 직접 지정도 가능).
  - 생성된 결과를 **파워포인트 안에서 직접 수정 가능** (다른 전용 툴은 자유도가 낮음).
  - 내용을 모르면 "알아서 조사해서 슬라이드 만들어줘" 가능.
  - 픽토그램·아이콘·PNG 이미지를 자동 생성해줌.
- **단점**: 도형 정렬(가운데 맞춤 등)이 흐트러질 때가 있음 → 수동 보정 필요. "몇 페이지랑 똑같이 만들어줘"처럼 지시하면 개선.
- 비교: Gamma/Genspark는 세 장 무료 제한 + 템플릿 주입 어려움.

### AI로 엑셀 다루기 예제

- 데이터
  - 실습용 데이터 구조: 주문번호, 주문일자, 연/월, 판매 지역, 담당자 ID, 상품 ID, 채널, 소속, 연락처, 할인 등으로 구성.
  - 기존 방식이라면 VLOOKUP/INDEX/MATCH/COUNTIF/SUMIF 같은 함수를 조합해 작성해야 하는 작업들.
  - 2024년 1~12월 임의 데이터 기준 총 600건.
- 담당자 아이디별 매출 금액·등급을 채우는 작업을 **"2칸 채워줘"** 한마디로 처리.
- AI가 시트 내용을 먼저 스스로 확인한 뒤 값을 자동 채움. 결과는 숫자 값이 아니라 **실제 수식**이 들어가 있어서 데이터 변경 시 자동 반영.
- 마스터 데이터에 없는 ID(예: EMP8999)는 오류로 표시되며, ID를 교정하면 즉시 재계산됨.
- 월별 판매 집계
  - "월별 판매 데이터를 집계해줘"라는 자연어 요청만으로 집계표 생성.
  - AI가 필요한 항목(주문 건수, 순 매출 등)과 그룹 기준을 역질문하고, 답에 따라 표를 구성.
  - 생성된 주문 건수 600건이 실제 원본 행 수와 일치함을 교차 검증.
- "시계열 그래프로 만들어줘" 한 줄로 차트 자동 생성.
- 성과 분석 대시보드 생성
  - 별도 시트에 **담당자 직원 성과 분석 대시보드**를 만들어달라고 요청.
  - AI가 KPI 지표(순매출, 평균 주문 금액, 달성률, 반품 건수·반품률)와 차트를 스스로 구성.
  - 달성률 색상 강조(마이너스는 빨간색), 랭킹 TOP3 등을 포함한 상당한 완성도의 결과물 제공.
  - 목표가 너무 높다는 판단에 따라 **"목표를 10분의 1로 줄여줘"** 요청 → 즉시 원본 시트·대시보드 모두 자동 재반영.

### AI 활용한 엑셀 작업

- PPT·이미지 생성은 후처리가 필요하지만 **엑셀은 후처리가 거의 없다**는 점이 특징.
- 컬럼을 미리 써두지 않아도, 말로만 설명해도 알아서 계산 수식을 넣어줌.
- 템플릿 한 번 만들어두면 오래 재사용 가능하므로 투자 대비 효과가 큼.
- 결론: **엑셀은 이제 "공부해서 배우는" 도구가 아니라 "시키는" 도구**.

### AI 시대의 3대 직업군

일론 머스크, 젠슨 황, 알트만 등 실리콘밸리 인사들이 공통적으로 언급하는 3개 직업군:

1. **AI를 개발하는 엔지니어**
   - 앤드류 응, 제프리 힌튼 같은 극소수 천재.
   - 전 세계 100~1,000명 수준, 연봉 약 1,300억 원대로 오타니·호날두 이상.
2. **AI로 대체할 수 없는 육체 노동자**
   - 작년까지는 공감
   - 중국 로봇(복싱·달리기) 영상 등을 보면 로봇 인건비가 사람보다 싸지는 순간 대체 가능성이 커짐.
   - 부천 중소공장 사례로, 외국인 노동자도 꺼리는 반복 작업에 로봇팔 도입이 이미 진행 중.
3. **AI를 잘 활용하는 전문직** => 우리가 지향해야 할 포지션.

### 진짜 경쟁력은 "전문성"

- "AI가 너의 일자리를 뺏는 게 아니라, AI를 잘 활용하는 사람이 뺏는다"는 말에는 동의.
- 다만 **중요한 것은 "AI 활용"이 아니라 "전문직·전문성·도메인 지식"**
- 이유: AI 활용은 허들이 너무 낮아졌고 누구나 쓸 수 있기 때문. 진입 장벽이 사라진 곳에 경쟁력은 존재하지 않음.
- 강사 본인 경험
  - 과거 6개월~1년 걸리던 머신러닝 프로젝트가 이제 2~3개월이면 끝남.
  - 오히려 **평가·테스트 단계가 시간을 더 먹는다**.
- 여기서 **전문직**이란 의사·변호사를 뜻하는 것이 아니라, 일하며 쌓은 경험과 도메인 지식의 깊이를 의미.

### 카메라-화가 비유와 역사적 관점

- 1837년 카메라 등장 직후 화가들은 "직업이 사라진다"고 걱정했으나 오히려 모네·피카소 등 **다양한 화풍**이 탄생하고, 지금도 극사실주의 화가는 높은 평가를 받음.
- 아름다움의 관점 자체가 변화한 결과.
- 역사적으로 **기술 발전으로 실업률이 영구적으로 증가한 적은 없다** — 러다이트 운동, 전기혁명, 정보혁명 모두 마찬가지.
- 인터넷으로 해외 사진을 볼 수 있게 되었을 때 "해외여행이 줄 것"이라 예측했으나 실제로는 오히려 증가.

### AI 시대의 업무시간·여가·기본소득

- **주 4.5일 근무**는 R&D·서비스직·육체 노동 제외 상당수 업무에서 충분히 가능
- 그러나 한국 문화상 **시간이 생기면 쉬기보다 다른 일을 더 하는 경향**이 있음.
- 실리콘밸리에서는 **"AI 기본소득(AI Basic Income)"** 논의가 활발. 머스크의 뇌 칩 연구도 같은 맥락. 상위 10~20% 외에는 일자리가 없어질 것이라는 전제로, AI로 돈 버는 기업이 소득을 분배해야 한다는 주장.
- 케인스의 100년 전 예언("기술 발전으로 미래 세대는 여가 시간이 늘어날 것이다")이 실제로 이루어지고 있음 — 테슬라 오토파일럿으로 운전 중 유튜브를 보는 것도 같은 맥락.

### 결론

툴을 알려주는 것보다 중요한 것은

- **"AI를 어떻게 대할 것인가"**
- **"AI에 집착하지 말고 문제 해결을 중심에 두는 것"**.
- 활용은 당연히 중요하지만, 진짜 활용을 잘 하는 사람은 **전문성을 갖춘 사람**
