D2 프롬프트
이 폴더에 영수증 파일들이 있어. 사진(PNG)도 있고 PDF도 있어.

각 영수증에서 아래 항목을 읽어서 경비 정산용 엑셀 파일로 만들어 줘.
- 사용일자 / 사용처 / 사업자번호 / 내역 / 금액 / 결제수단 / 파일명

그리고 아래도 함께 처리해 줘.
1. 카테고리 열을 추가해서 식비 / 카페 / 교통 / 도서·자료 / 사무용품·다과 로 분류해 줘.
2. 카테고리별 소계와 전체 합계를 표로 만들어 줘.

오히려 늘 수도 있습니다. 줄어드는 건 만드는 시간입니다. 4월 교육의 딥리서치와 똑같습니다 — 생성 37분, 검증 하루.

02

틀린 결과가 파일로 조용히 저장됩니다

채팅은 눈앞에서 읽고 넘어가지만, 파일은 안 읽고 제출할 수 있습니다.

03

사용량을 많이 씁니다

채팅보다 훨씬 빨리 한도에 닿습니다. 아무 일에나 켜지 마세요.

04

완전 자동화는 목표가 아닙니다

사람이 판단할 지점은 남겨두세요. 승인 모드를 켜두는 이유가 그것입니다.

"AI가 일자리를 뺏는 게 아니라 AI를 잘 쓰는 사람이 뺏는다"에는 동의합니다. 다만 활용은 진입장벽이 거의 없습니다. 코워크가 만든 정산표가 규정에 맞는지, 리서치 요약이 인용해도 되는 수준인지 아는 사람이 필요합니다. 그 판단은 오늘 배운 도구가 못 합니다.
