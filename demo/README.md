# 시연용 데모 데이터

[클로드 코워크 발표 진행가이드](../docs/260812_클로드_코워크_발표_진행가이드.md)의 시연에 쓰는 예제 파일입니다.
모든 내용은 **가상의 연구소/경영지원 업무를 흉내낸 예제**이며 실제 조직·인물·기업과 무관합니다.

## 생성 / 재생성

```bash
python3 demo/tools/generate_demo_data.py
```

Pillow가 필요합니다 (`pip install pillow`). 영수증 이미지는 macOS 한글 폰트(AppleGothic)를 사용합니다.

## 폴더 구성

| 폴더 | 시연 | 내용 |
|---|---|---|
| `01_폴더정리/원본/` | D1 | 이름만으로는 내용을 알 수 없는 파일 11개 (빈 파일 2개 포함) |
| `02_영수증정산/영수증/` | D2 | 영수증 사진 6장(PNG) + KTX 승차권(PDF). `IMG_2046.png`은 **일부러 흐리게** 만들어 "확인 필요" 동작을 시연용 |
| `03_회의록/원본/` | D3 | 회의록 7개. 담당자가 겹치고 기한이 흩어져 있으며, P-102 원료 수급 이슈가 3개 회의에 반복 등장 |
| `04_리서치소스/소스/` | D4 | 리서치 소스 10개. 학술논문·정부자료·시장보고서·뉴스·IR·블로그·익명 커뮤니티까지 **신뢰도가 의도적으로 섞여 있음** |
| `05_브리핑배포/` | D5 | `소스/` 주간 브리핑 원고 1개 + `참고/` 스타일 가이드 4개(사내공지·임원보고·메일·메신저) |
| `07_대시보드/` | D7 | 예산 집행 내역 CSV + 예산 계획 CSV. **구글 스프레드시트로 변환해서** 사용 |

## 시연 전 준비

발표 당일에는 이 폴더를 데스크톱으로 복사한 뒤, 각 시연 직전에 `원본` → `사본` 을 한 번 더 복사해서 **사본에만** 코워크를 연결하세요.

```bash
mkdir -p ~/Desktop/코워크_시연
cp -R demo/01_폴더정리 demo/02_영수증정산 demo/03_회의록 \
      demo/04_리서치소스 demo/05_브리핑배포 demo/07_대시보드 \
      ~/Desktop/코워크_시연/
```

`원본 → 사본` 복사를 발표 중에 **화면에서 직접 보여주면** 안전수칙(중요한 원본은 복사본으로 작업)이 말보다 잘 전달됩니다.
