# 사내 공지 스타일 가이드

## 목적
전 직원이 30초 안에 '내가 해야 할 일'을 파악하게 한다.

## 포맷 규칙
- 첫 줄에 한 문장 요약을 굵게 쓴다.
- 본문은 3~5개 항목의 불릿으로 구성한다.
- 기한이 있는 항목은 반드시 `[~MM/DD]`를 항목 앞에 붙인다.
- 마지막에 '문의: 담당자명(팀)' 한 줄로 끝낸다.
- 전체 길이 400자 이내.

## 톤
- 건조하고 사실 중심. 감탄사·이모지 사용 금지.
- 존댓말(합니다체) 사용.

## 피해야 할 것
- '~할 예정입니다' 같은 모호한 표현 대신 확정된 날짜를 쓴다.
- 배경 설명을 길게 쓰지 않는다. 필요하면 '상세: 첨부 참고'로 넘긴다.

## 예시
**3분기 보고서 양식이 변경되었습니다.**
- [~07/24] 신규 양식으로 작성 전환
- [~07/17] 작성 가이드 1장 요약본 확인
- 기존 양식 작성분은 재작업 필요
문의: 윤도현(경영지원)
